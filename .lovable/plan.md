## เป้าหมาย
ตรวจสอบทุกปุ่มและลิงก์ในเว็บไซต์ว่าใช้งานได้จริง ไม่มีลิงก์เสีย, ปุ่มค้าง, หรือ route ที่ไม่ถูกต้อง

## ขั้นตอนการตรวจสอบ

1. **สแกน routes ทั้งหมด**
   - list `src/routes/` เพื่อรวบรวมหน้าที่มีอยู่จริง
   - เทียบกับ `<Link to="...">` และ `navigate({to:...})` ทั้งหมดในโค้ด ว่าชี้ไป route ที่มีจริงหรือไม่

2. **สแกนปุ่มและลิงก์**
   - หา `<Button onClick=...>`, `<a href=...>`, `<Link ...>` ทั้งหมด
   - ตรวจ href ภายนอก (mailto, tel, social) ว่าครบถ้วนถูกต้อง
   - ตรวจ handler ว่าไม่ใช่ no-op หรือ TODO

3. **ทดสอบใน browser ด้วย Playwright**
   - เปิดแต่ละหน้า, กดปุ่ม nav หลัก, ปุ่ม CTA, ลิงก์ footer, ปุ่ม gallery/upload
   - เก็บ console errors และ network 404/500
   - ถ่าย screenshot จุดที่พบปัญหา

4. **สรุปรายงาน**
   - ตารางแสดง: หน้า / องค์ประกอบ / สถานะ (✅ ใช้ได้ / ❌ พัง / ⚠️ ควรปรับ) / วิธีแก้
   - ถ้าพบจุดพัง จะเสนอแก้เป็นแผนย่อยให้อนุมัติก่อนแก้จริง

## สิ่งที่จะยังไม่แก้ในรอบนี้
รอบนี้เป็นการตรวจสอบเท่านั้น จะยังไม่แก้โค้ด — ถ้าพบปัญหา จะแจ้งเป็นรายการให้อนุมัติก่อนลงมือแก้
